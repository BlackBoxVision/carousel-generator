## Design Context

### Users
Marketers, creators, designers, agencies, and AI-assisted users create and refine branded social media carousels in a browser-based editor.

### Brand Personality
Precise, practical, and confident. The editor should feel calm and dependable during fast content production.

### Aesthetic Direction
Dark, technical, and restrained. Use clear grouping, strong alignment, purposeful contrast, and compact controls rather than decorative effects.

### Design Principles
- Make the next action obvious without adding labels everywhere.
- Use flex grouping and spacing to create rhythm before adding decoration.
- Keep destructive actions visually and spatially separate.
- Preserve the existing editor palette and Material Web behavior.
- Favor readable, export-safe UI and accessible touch targets.
